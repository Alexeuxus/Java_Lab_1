# Java_Lab_1
Репозиторий для лабораторной работы №1 по Джаве "Создание класса для работы с матрицами комплексных чисел".

## Использование
При запуске файла выберите желаемое действие (введите число от 0 до 8) и следуйте инструкциям в терминале.
## Создание матриц
При создании матрицы сначала напишите число строк и столбцов через пробел, затем для каждого элемента его действительную и мнимую части

## Примечание
Для вычисления определителя и обратной матрицы используется метод Гаусса с выбором главного элемента.
